C. Response Status Guide

Not contacted: No message has been sent.

Contacted: An outreach message has been sent.

Replied: A response has been received.

Interested: The contact has shown interest.

Follow-up required: A follow-up is due.

Declined: The contact declined.

Partnership confirmed: Both parties have agreed to collaborate.

D. Outreach Guidelines

Verify profile and contact information before outreach.

Personalize each message.

Use approved company communication channels.

Record the actual date of every message.

Update the response status accurately.

Follow up professionally when appropriate.

Never mark a partnership as confirmed without mutual agreement.
